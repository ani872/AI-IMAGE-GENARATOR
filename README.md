# 🎨 AI Image Generator

A beautiful, fully responsive, and fast AI Image Generator built using **HTML, CSS, and vanilla JavaScript**. It leverages the powerful **Pollinations AI** to generate stunning, high-quality images directly from text prompts—completely for free, without needing any API keys or registrations!

## ✨ Features

- **No API Key Required**: Powered by Pollinations.ai open API, meaning you can generate images without the hassle of accounts, tokens, or CORS issues.
- **Dark & Light Mode**: Aesthetic glassmorphism UI design with a smooth theme toggle.
- **Multiple Aspect Ratios**: Choose between Square (1:1), Landscape (16:9), and Portrait (9:16).
- **Batch Generation**: Generate up to 4 images at a time! 
- **Smart Throttling**: Intelligent request staggering and auto-retry mechanisms to ensure images are always generated successfully, without overwhelming free servers.
- **Prompt Magic**: A magic wand button that auto-fills the input with highly detailed, optimized example prompts.
- **One-Click Download**: Directly download your generated masterpieces.

## 🛠️ How to Use Locally

1. Clone this repository to your computer:
   ```bash
   git clone https://github.com/ani872/AI-IMAGE-GENARATOR.git
   ```
2. Simply open `index.html` in any modern web browser.
3. Type a descriptive prompt (e.g., *"A highly detailed close-up portrait of an old wise man, cinematic lighting, 8k"*).
4. Select the number of images and aspect ratio.
5. Click **Generate** and watch the magic happen!
